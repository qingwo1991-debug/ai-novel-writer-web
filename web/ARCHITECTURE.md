# 原生 Web 全功能重构架构

本工程从 AI-Novel-Writer 现有领域实现提取纯 Node 服务，保留 React/CodeMirror 功能界面。运行目标不含 Electron、Xvfb、VNC，也不以同名 Electron shim 冒充 Web 后端。

## 组件

- **HTTP gateway**：静态资源、反向代理身份、同源会话、CSRF、明确操作清单、上传下载、SSE、限流和项目路由。
- **平台接口**：operations 注册领域操作；ClientSink 传送会话事件；dialogHost 将选文件/保存等动作交给浏览器；appHost 供应受控服务目录/语言。
- **全局 worker**：全局配置、模型密钥、提示词、skills、应用数据及 MCP 的单写入口；先经原迁移门安装有效 generation。
- **项目 worker**：每个规范项目仅一个纯 Node 进程，维护既有 SQLite、租约和生成 owner；不同项目不共享可变数据库单例。同项目多标签使用显式写占有权，不能静默互踢租约或覆盖编辑。
- **浏览器 transport**：HTTP operations + SSE。没有 window.aiNovelAPI 注入，也不加载桌面主进程。

## 浏览器文件语义

- 创建作品在受控服务端书库；打开作品从受控清单选择。用户不能指定服务器任意路径。
- 本地文件通过真实浏览器文件选择/上传，转换为绑定会话的短期 grant。导入检查、拆章及确认仍用已有领域服务。
- 导出在独立临时目录生成，浏览器真实下载；多文件打包。归档恢复是上传归档后在书库创建新副本。
- 桌面窗口控制、操作系统目录展示、桌面安装更新不作为 Web 功能照搬，分别替换为页面导航、下载列表和服务器部署说明。

## 安全与并发门

- 网关只经回环后端和现有 nginx 密码入口开放。nginx 传递已认证主体，后端不接受无主体的公共请求。
- 不把注册表中的全部 IPC 自动公开。明确操作清单拒绝桌面/测试操作，额外验证项目、参数体积、上传会话和任务调用者。
- 修改请求要求 cookie 会话、CSRF token、自定义客户端 ID 和同源 Origin；SSE 绑定会话与标签。
- 模型返回公开配置（空 apiKey + hasCredential），保存空 key 保留原凭据，只有端点/服务商一致时才允许复用；绝不返回服务端 key。
- 模型/备份网络地址必须经管理员允许的端点策略；MCP 仅连接服务器预配置 ID，不接收浏览器任意 command/env。
- 不把异步请求临时切换到某全局数据库。每项目 worker 一次打开，写标签唯一，切换项目由网关路由。
- 页面断开不等于任务取消。当前前端批量编排必须明确断线暂停/恢复，迁移记录不得把单次生成持久化称为全部后台续跑。

## 验收原则

FEATURE-MATRIX.md 为逐项完成记录。构建成功/界面可开不等于全功能通过；真实模型、上传下载、归档恢复、SQLite 重启持久化、多标签及安全负例分别验证。外部 Embedding/WebDAV/MCP 凭据缺失项不能标记完成。
