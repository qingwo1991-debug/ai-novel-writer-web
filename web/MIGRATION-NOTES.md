## 已实现的运行结构

| 层 | 实现与边界 |
| --- | --- |
| 浏览器 | 独立 `vite.web.config.ts`，复用完整阶段/资源/编辑/运行界面；HTTP operations + SSE，没有 `window.aiNovelAPI` 注入或假 Electron。 |
| 中立平台 | `electron/platform/` 配置 `appHost`、操作注册、`ClientSink`、浏览器对话框、外部导航和 secret-store；先配置，再动态载入会计算全局目录的业务模块。 |
| HTTP网关 | `web/server.mjs`：可信认证入口身份、cookie/CSRF/Origin、明确操作表、项目路由、调用者绑定 grant、上传/下载、限额、SSE与短期重放。 |
| 全局worker | 全局配置/模型/提示词/Skills/MCP入口，复用既有 generation/迁移门；不把未注册内部管理操作暴露为HTTP。 |
| 项目worker | 每个规范项目一个纯Node进程，一次打开，隔离原有单项目SQLite/租约/owner单例；同项目不同标签不能静默互踢。相同标签刷新保留已有调用sink。 |
| 文件 | 本地真实上传→短期会话授权；受控服务器书库创建/选择；导出临时目录→真实下载；归档恢复创建副本，不覆盖原作品。 |
| 打包 | `Dockerfile.web`、`docker/compose.web.yaml`、`docker/web-entrypoint.sh`；Node22-slim、Python安全helper、flock和35包运行依赖闭包，不复制完整桌面依赖树。 |

明确操作表目前为 **281允许（217项目/42全局/22灵活）+13排除=294分类名称**。排除桌面窗口、桌面更新、测试钩子和MCP配置路径；操作名前缀不是授权通配符。实际定稿、复查恢复、权威定稿知识库导入等有显式入口。

## 不能削弱的业务边界

- 事务化生成run/attempt/artifact、冻结来源与hash/CAS、审稿周期/修订谱系、定稿outbox/发布receipt仍由服务器权威验证。流出文字不等于提交成功。
- 同一run的请求使用事务派发门；未知服务商结果不自动重发。恢复必须显式引用已有候选/尝试，失败或部分产物不能冒充完整产物。
- `kb_import`、`chapter_notes`为必要定稿后处理；已经声明的`character_cards`失败也阻止自动批量推进。没有声明的可选步骤不凭空制造要求。
- 已完成定稿知识库导入绑定权威来源，确定性文档ID/完整receipt重放不重复嵌入计费；证据缺失/损坏/被改走显式修复，不静默重建。
- 合并后的待复查有持久可发现入口；打开作品/刷新只读恢复，不自动发起AI。
- 工作流仍由浏览器编排：**运行时保持页面打开**。服务端保存单次请求/效果与恢复信息，不承诺整条流程无页面后台续跑、跨root全局调度或端到端exactly-once。见 [WORKFLOW-LIFECYCLE.md](WORKFLOW-LIFECYCLE.md)。

## 认证、凭据与集成

- 一个共享作者书库与全局模型配置，**不是多租户系统**。调用者/项目/标签/grant隔离不等于不同用户私有作品库。
- 后端仅发布127.0.0.1:6081；nginx须先Basic Auth，再覆盖`X-Novel-User $remote_user`，清除Authorization。身份头本身不是认证。保持原密码/证书，HTTP Basic不加密，优先HTTPS/VPN。
- 模型key沿用服务器私有`models.json`（写入0600），目前不声称模型配置全字段加密；外层JSON/live+重放SSE只返回空key/hasCredential并清除已注册精确密钥。空key仅在同ID/服务商/协议/端点匹配时恢复。完整备份含秘密，不能公开。
- 使用secret-store的WebDAV凭据采用服务器持钥AES-256-GCM；密钥跟随完整卷备份，不是OS keychain，也不能防读取宿主私钥的管理员。
- 脱敏只识别已注册精确字串（>=4 UTF16单元）与明确敏感字段，不保证未注册/短/编码/分事件字串、日志或二进制下载；不改内部路由、证明或作者下载内容。
- 模型生成/发现、每批嵌入与WebDAV实际派发按精确允许origin且禁止重定向；部署代理不可由作者偏好覆盖。这不是全局fetch/DNS防火墙或子进程网络沙箱。
- MCP只接服务器预配置ID；最小继承env、受控cwd/HOME、1MiB请求、32待处理、4MiB输入/输出、512工具/资源、10秒超时、已发现工具门与固定错误。**可信管理员配置的程序仍以worker身份读写数据卷，不是OS沙箱**。SSE在原基线也未实现。
- WebDAV/向量嵌入/外部MCP未配置的真实服务验收保持live-unverified，不能发明凭据或宣称通过；实现存在也不等于活体验收。
